# Security policy

urMQTT is pre-alpha. No release is fit for production yet.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub Security Advisories](https://github.com/zeljan-alduk/urMQTT/security/advisories/new).
Include the affected commit, a reproducer (a fuzz input is ideal) and the impact
you expect.

You can expect an acknowledgement within 7 days. Fixes are released as a new
image, because urMQTT has no in-place update mechanism by design.

## Scope

The parsers (MQTT, TLS records, TCP/IP, configuration, DTB/ACPI) and anything
reachable from TCP 8883 are in scope. The threat model lives in
[docs/SECURITY.md](docs/SECURITY.md).

Dev certificates generated by `scripts/gen-dev-certs.sh`, and the dev images
attached to GitHub releases, embed throwaway keys and are **not** secrets.
Reports about them are out of scope.
